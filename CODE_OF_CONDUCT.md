# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

We want GeorgNative to be a welcoming project for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, caste, color, religion, or sexual identity and orientation.

- Be kind and respectful, especially with newcomers and in code review.
- Discuss ideas, not people. Accept that others may disagree and give constructive feedback.
- No harassment, insults, trolling, sexualized language or imagery, or publishing others' private information.

## Scope

This code applies in every project space (issues, pull requests, discussions, reviews) and when someone represents the project in public.

## Reporting

Report unacceptable behavior to the maintainers at **oi@dasgeorg.cc**. Every report is reviewed promptly and handled confidentially. Maintainers will act as described in the [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines) of the Contributor Covenant.
